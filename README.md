# NEMO

인테리어 스튜디오 네모의 공식 웹사이트입니다.

- 서비스 소개, 포트폴리오, 뉴스룸, 상담 신청
- 관리자에서 게시글·사진·홈페이지 콘텐츠 관리
- 라이트·다크 모드와 모바일 지원

## 로컬 실행

```sh
npm ci
npm run dev
```

http://127.0.0.1:4317 에서 확인합니다.
관리자 사용법은 [ADMIN.md](ADMIN.md)를 참고하세요.

## 개발

`dist/`는 웹 화면, `worker/`는 서버 API입니다.
`npm run build`로 빌드하고 `npm test`로 확인합니다.
운영 콘텐츠는 D1·R2에 저장되며, GitHub 저장과 사이트 배포는 별도입니다.
