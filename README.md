# NEMO 웹페이지 시안

Figma 스토리보드 UjZpmx7q2Min2JTAIXq5FK를 바탕으로 제작한 세로 스크롤 페이지.

- Home → 사진 확장·축소 → 상담 안내 → 주거 → 상업 → 포트폴리오·후기 → 작업 과정 → 상담 → 푸터 순서.
- 반복 프레임은 연속 스크롤 장면으로 통합했다. 모바일에서는 카드가 가로로 넘겨진다.
- 원본 사진·아이콘·로고는 Figma에서 제공받은 파일이며 임시 URL을 사용하지 않는다.
- 빈 이미지 영역은 시안용 3D 콘셉트로 보완했다. 실제 시공 사례로 표시하지 않는다.
- 상담 폼은 서버에 내용을 저장하지 않으며 사용자의 이메일 앱에서 초안을 연다. 직접 전송해야 한다.
- 뉴스룸·채용·약관은 상세 내용이 없어 시안 안내 화면으로 연결한다.
- 실제 수치가 없는 000건 표기는 제외했다. 후기 문구는 스토리보드 원문이며 확인 전 시안으로 표시한다.
- 모션 감소 설정에서는 스크롤 전환을 끄고 내용을 정적으로 보여준다.

## 로컬 실행

`node server.mjs` 실행 후 http://127.0.0.1:4317 에서 확인한다.

## 이미지 제작

기본 내장 image_gen을 사용했다. 최종 이미지: dist/assets/space-illustrations.png

제작 프롬프트: NEMO 인테리어 페이지에 사용할 2열 3행 3D 오브젝트 아틀라스. 거실, 카페, 견적 클립보드, 줄자와 도면, 소재 샘플, 완성된 집을 각각 독립 패널에 배치. 밝은 회색 배경, 크림·원목·버터 옐로·세이지 색상, 둥근 형태, 부드러운 스튜디오 조명, 매트한 클레이·새틴 재질. 동일한 아이소메트릭 각도, 텍스트·로고·워터마크 없음.

## 검증 범위

코드 문법, 이미지 파일 및 내부 링크를 확인했다. 로컬 화면 열기는 앱 브라우저 보안 정책에 의해 차단되어 데스크톱·모바일 실제 화면 QA는 미확인이다.
