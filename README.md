# NEMO — 가능성을 담다, 공간을 바꾸다

Figma 스토리보드를 바탕으로 만든 인테리어 스튜디오 웹페이지 시안입니다.

## 구성

- 왼쪽의 작은 섹션 이동바와 검정색 활성 표시
- 첫 사진 확대 → 사진 위 문구·상담 카드 등장 → 사진 축소 순서로 이어지는 스크롤 흐름
- 상담 카드는 최대 550px의 크기로 사진 오른쪽에 등장하고, 아래로 내려오는 곡선을 따라 축소되어 주거 이미지 카드 위치로 이동
- 견적 소개 문구는 사진 내부의 원래 위치 유지
- 첫 사진이 위로 사라지고, 같은 위치의 주거·상업 카드로 이어지는 스크롤 전환
- 스크롤에 따라 주거공간 → 주거, 상업공간 → 상업으로 바뀌는 제목
- 제목 타이핑, 카드의 무작위 순차 등장과 가로 이동
- 공간에 대한 바람을 담은 한 줄 전광판
- 주거·상업 설명과 이미지 카드를 하나의 묶음으로 화면 중앙에 정렬
- 위로 스크롤하거나 하단에 도착하면 다시 나타나는 상단 메뉴
- 해요체로 정리한 안내 문구
- 배경과 바닥 그림자를 제거한 투명 PNG 일러스트
- 옅은 완성 문장 위에 빈 상태부터 밝은 민트색 글자가 채워지고, 축소 시 검정으로 바뀌며 완성되는 라이프스타일 제목과 검정 글자에서도 민트색을 유지하는 두꺼운 세로 커서
- 분류 버튼의 슬라이딩 표시와 카드 페이드 전환
- 모바일 대응과 모션 감소 설정 지원

## 실행

Node.js 설치 후 저장소 폴더에서 `node server.mjs`를 실행하고 http://127.0.0.1:4317 을 엽니다. 별도 패키지 설치는 필요하지 않습니다.

## 파일

- `dist/index.html`: 페이지 구조와 문구
- `dist/styles.css`: 레이아웃, 반응형, 이미지 배경 처리
- `dist/app.js`: 스크롤 전환, 메뉴, 카드, 상담 화면
- `dist/assets/`: 페이지 사진과 이미지
- `server.mjs`: 로컬 미리보기 서버

## 수정 이력

최초 시안과 섹션 이동·스크롤 연출 수정본이 각각 커밋으로 기록되어 있습니다. GitHub의 Commits에서 변경 사항을 비교할 수 있습니다.

GitHub 업로드는 Sites 배포와 별개입니다. 이 저장소의 변경이 사이트에 자동 반영되는 연결은 아직 설정하지 않았습니다.

## 수정 요청용 번호

01 첫 화면 / 02 주거 / 03 상업 / 04 공간 모아보기 / 05 후기 / 06 진행 과정 / 07 상담 / 08 하단 정보.

각 주요 요소에 작은 번호를 표시했습니다. 예를 들어 02-01은 주거 설명, 02-02는 주거 이미지 카드, 04-01은 라이프스타일 제목이며 04-03부터 04-09까지는 공간 카드입니다.

## 시안 안내와 검증

사진은 스토리보드 레퍼런스이며, 3D 이미지는 생성한 디자인 콘셉트입니다. 전광판 문구는 공간에 바라는 모습을 표현한 문장이며 실제 고객 후기가 아닙니다.

상담 폼은 서버에 내용을 저장하지 않고 이메일 앱에서 초안을 엽니다. 전송은 사용자가 직접 합니다. 뉴스룸·채용·약관은 시안 안내 화면입니다.

JavaScript 문법과 내부 링크·페이지 구조를 검사했고, 배포된 화면에서 데스크톱·모바일 정렬 및 스크롤 동작을 확인했습니다.
