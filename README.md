# NEMO — 가능성을 담다, 공간을 바꾸다

인테리어 스튜디오 네모의 웹사이트입니다.

## 구성

- 공통 메뉴: 서비스 → 포트폴리오 → 회사소개 → 뉴스룸 → 채용
- 뉴스룸: 추천 이야기, 분류별 목록, 기사 상세와 관련 이야기
- 포트폴리오: 공간 유형·스타일 필터, 검색·정렬, 개별 상세 페이지와 이미지 갤러리
- 상담 신청: 별도 페이지에서 공간 정보 → 연락 정보 → 내용 확인의 세 단계로 진행
- 사무 공간 소개와 포트폴리오, 공간 유형별 분류
- 서비스·회사소개는 별도 페이지로 연결하고 채용은 안내 창으로 표시
- 주소 검색과 상세 주소 입력, 넓어진 면적·예산 범위 및 직접 입력
- 이용약관·개인정보처리방침·수집 및 이용 동의·마케팅 선택 동의
- 왼쪽의 작은 섹션 이동바와 검정색 활성 표시
- 첫 사진 확대 → 사진 위 문구·상담 카드 등장 → 사진 축소 순서로 이어지는 스크롤 흐름
- 상담 카드는 오른쪽에서 안정된 크기로 등장해 잠시 머물고, 왕복 없이 부드럽게 내려오며 축소되어 주거 이미지 카드 위치로 이동
- 견적 소개 문구는 사진 내부의 원래 위치 유지
- 첫 사진이 위로 사라지고, 같은 위치의 주거·상업 카드로 이어지는 스크롤 전환
- 스크롤에 따라 주거공간 → 주거, 상업공간 → 상업으로 바뀌는 제목
- 제목 타이핑, 카드의 무작위 순차 등장과 가로 이동
- 국내/해외 탭: 남한 지도 위 7개 민트색 지역 후기 핀과 호주 - 향수매장 목록
- 지도 아래 왼쪽 한국 현재 시간, 가운데 Total Projects - 200+ (Abroad 5+), 오른쪽 Data - NEMO
- 공간에 대한 바람을 담은 한 줄 전광판: 동일한 두 반복 묶음을 하나의 흐름으로 이동하며 화면 폭에 맞춰 길이를 확보
- 주거·상업 설명과 이미지 카드를 하나의 묶음으로 화면 중앙에 정렬
- 위로 스크롤하거나 하단에 도착하면 다시 나타나는 상단 메뉴
- 해요체로 정리한 안내 문구
- 배경과 바닥 그림자를 제거한 투명 PNG 일러스트
- 옅은 완성 문장 위에 빈 상태부터 밝은 민트색 글자가 채워지고, 축소 시 검정으로 바뀌며 완성되는 라이프스타일 제목과 검정 글자에서도 민트색을 유지하는 두꺼운 세로 커서
- 분류 버튼의 슬라이딩 표시와 카드 페이드 전환
- 모바일 대응과 모션 감소 설정 지원
- 해외 목록은 전광판과 동일한 크기(데스크톱 19px, 모바일 17px)로 표시
- 진행 과정은 한 화면에 고정되어 상담·실측·설계·완성의 일러스트가 스크롤에 따라 전환되고, 단계 버튼과 방향키로 직접 선택 가능
- 단계 설명은 이전 문구가 사라진 다음 새 문구가 나타나 겹침을 방지하며, 모션 감소 설정에서는 네 단계를 순서대로 표시

## 실행

Node.js 설치 후 저장소 폴더에서 `npm ci`, `npm run dev`를 실행하고 http://127.0.0.1:4317 을 엽니다. 관리자 설정과 글쓰기 사용법은 [ADMIN.md](ADMIN.md)를 참고하세요.

## 파일

- `dist/index.html`: 페이지 구조와 문구
- `dist/styles.css`: 레이아웃, 반응형, 이미지 배경 처리
- `dist/app.js`: 홈페이지 스크롤 전환, 메뉴, 상세 페이지 이동
- `dist/newsroom.html`, `dist/story.html`: 뉴스룸 목록과 기사 상세
- `dist/portfolios.html`, `dist/portfolio.html`: 포트폴리오 목록과 공간 상세
- `dist/inquiry.html`: 상담 신청 페이지
- `dist/pages.css`, `dist/pages.js`: 하위 페이지의 반응형 화면과 상호작용
- `dist/content.js`: 최초 콘텐츠 참조 (운영 글은 D1/R2에 저장)
- `dist/admin.html`, `dist/admin.js`: 실시간 본문 편집과 관리자 화면
- `dist/cms-render.js`, `dist/cms-render.css`: 편집기와 공개 글이 공유하는 렌더링
- `worker/`: 로그인·권한·게시·조회수·휴지통 정리 API
- `dist/shared.css`, `dist/shared.js`: 메뉴 정렬, 공통 안내 창과 약관
- `dist/assets/`: 페이지 사진과 이미지
- `server.mjs`: 로컬 미리보기 서버

## 수정 이력

최초 시안과 섹션 이동·스크롤 연출 수정본이 각각 커밋으로 기록되어 있습니다. GitHub의 Commits에서 변경 사항을 비교할 수 있습니다.

GitHub 업로드는 Sites 배포와 별개입니다. 이 저장소의 변경이 사이트에 자동 반영되는 연결은 아직 설정하지 않았습니다.

## 수정 요청용 번호

01 첫 화면 / 02 주거 / 03 상업 / 04 공간 모아보기 / 05 후기 / 06 진행 과정 / 07 상담 / 08 하단 정보.

각 주요 요소에 작은 번호를 표시했습니다. 예를 들어 02-01은 주거 설명, 02-02는 주거 이미지 카드, 04-01은 라이프스타일 제목이며 04-03부터 04-09까지는 공간 카드입니다.

## 시안 안내와 검증

상담 폼은 서버에 내용을 저장하지 않고 이메일 앱에서 초안을 엽니다. 전송은 사용자가 직접 합니다. 연락처 형식과 필수 항목을 확인하며, 선택한 포트폴리오의 공간 유형과 제목이 상담 페이지에 이어집니다. 채용·약관은 안내 화면입니다.

상담·AS 정보는 처리 종료 후 5년간 보관하는 안내를 적용했습니다. 마케팅 동의는 선택이며, 동의 후 최대 5년 또는 철회 시까지 중 먼저 도래하는 때까지 보관합니다. 동의 여부와 안내문 버전은 상담 이메일에 포함합니다.

JavaScript 문법과 내부 링크·페이지 구조를 검사했고, 배포된 화면에서 데스크톱·모바일 정렬 및 스크롤 동작을 확인했습니다.

하위 페이지의 분류·검색·초기화, 이미지 선택·확대·방향키, 상담 단계 이동·필수 항목·연락처 검증과 홈페이지 연결도 확인했습니다.
